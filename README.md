# إقرا (Iqra) — مساعد قراءة ذكي

> "إقرا... افهم ما تراه."

مساعد قراءة بالذكاء الاصطناعي يساعد الأشخاص الذين يجدون صعوبة في القراءة
(أميّون، كبار سن، ضعاف بصر) على فهم أي نص يظهر على شاشة هاتفهم، بخصوصية
كاملة وأقل عدد ممكن من الخطوات.

---

## حالة المشروع

**المرحلة الحالية: Phase 1 — Foundation ✅**

تم بناء الأساس الكامل للمشروع: المعمارية، نظام التصميم، الملاحة، حقن
الاعتماديات، هياكل الخدمات الست، والطبقة الأصلية (Native) الأولية. **لا
توجد ميزات وظيفية فعلية بعد** (OCR، ذكاء اصطناعي، سجل حقيقي) — هذه تُبنى في
المراحل القادمة فوق هذا الأساس.

---

## المعمارية

```
Clean Architecture + Feature-First
├── core/            (بنية تحتية مشتركة عبر كل الميزات)
│   ├── theme/        نظام التصميم (ألوان، خطوط، تباعد، انحناء)
│   ├── widgets/       مكوّنات قابلة لإعادة الاستخدام
│   ├── services/      واجهات الخدمات الست (Interfaces فقط + Stubs)
│   ├── router/         إعداد GoRouter
│   ├── di/             حقن الاعتماديات عبر Riverpod
│   ├── error/           Result<T> + Failure الموحّدين
│   └── l10n/generated/  (يُولَّد تلقائياً — غير مُدرَج في git)
├── features/         كل ميزة بطبقاتها الثلاث (presentation/domain/data)
│   ├── splash/ onboarding/ permissions/ home/
│   ├── history/ settings/ help/ about/  (Placeholder بصري فقط الآن)
│   └── component_gallery/  (أداة تطوير داخلية لمراجعة نظام التصميم)
└── shared/            عناصر مشتركة بين الميزات (مثال: PlaceholderPageBody)
```

**نمط الحالة/حقن الاعتماديات:** `flutter_riverpod` (بدون code generation في
هذه المرحلة، لتفادي الاعتماد على `build_runner` قبل استقرار بيئة التطوير
لديك — يمكن الانتقال إلى `@riverpod` لاحقاً بسهولة).

**الملاحة:** `go_router` — لا يزال الخيار الأنسب، لم يظهر بديل أحدث يستحق
الاستبدال.

**التدويل:** الحل الرسمي لـ Flutter (`flutter gen-l10n` + ARB files) بدل
`easy_localization`/`slang` المقترحين سابقاً في التصميم — **قرار مُحدَّث**
لأنه مدعوم رسمياً، Type-safe بالكامل، ولا يحتاج خطوة توليد يدوية. يعمل
تلقائياً عند `flutter pub get` بفضل `generate: true` في `pubspec.yaml`.

## نظام التصميم — قرار مهم يجب معرفته

تصدير Stitch المرفق (`stitch_iqra_ai_reading_assistant.zip`) يحتوي على
**تصميمين متنافسين**:

1. **"Iqra Design System"** — مُختبر بالعربية RTL عبر 5 شاشات (بما فيها
   الشاشة التي تستخدم شعار التطبيق الفعلي)، ويطابق تماماً الميزات المحددة
   في الوثيقة الأصلية (استمع/اشرح/ترجم).
2. **"Iqra Vision"** — استكشاف بديل بالإنجليزية فقط، بدون اختبار RTL.

**تم اعتماد النظام الأول (#1) كمرجع نهائي** لكل الرموز (ألوان، طباعة،
تباعد، انحناء) والمكوّنات في هذا التسليم. إذا كنت تفضّل اتجاه "Iqra Vision"
بدلاً من ذلك، أخبرني وسأُعدّل رموز التصميم بالكامل.

## الخدمات الأساسية (واجهات فقط — بلا تنفيذ بعد)

| الخدمة | الغرض | حالة التنفيذ |
|---|---|---|
| `OverlayService` | الزر العائم | واجهة + Stub |
| `ScreenCaptureService` | التقاط منطقة الشاشة (MediaProjection) | واجهة + Stub |
| `OcrEngine` | استخراج النص (نمط Strategy: محلي/سحابي) | واجهة + Stub |
| `TtsService` | تحويل النص إلى كلام | واجهة + Stub |
| `AiAssistantService` | الشرح/الترجمة (سحابي اختياري بموافقة) | واجهة + Stub |
| `HistoryRepository` | سجل القراءة | واجهة + Stub (في-الذاكرة) |

كل خدمة مُسجَّلة في `lib/core/di/providers.dart` كـ Riverpod `Provider`
يُرجع الـ **Interface** لا التنفيذ — استبدال أي Stub بتنفيذ حقيقي لاحقاً لا
يتطلب تعديل أي كود في طبقات الميزات المستهلِكة.

## ⚠️ قيود بيئة التنفيذ التي بنيت فيها هذا المشروع

بيئة التطوير التي استخدمتها لكتابة هذا الكود **لا تملك Flutter SDK ولا
Android SDK مثبَّتين، ولا صلاحية وصول شبكي لـ `pub.dev`** (فقط GitHub
وبضعة مستودعات حزم أخرى مسموحة). لذلك:

- **لم أتمكن من تشغيل `flutter pub get` أو `flutter build apk` فعلياً
  للتحقق من نجاح البناء.** كل الكود كُتب يدوياً بعناية قصوى مطابقاً لبنية
  Flutter/Android القياسية، وراجعته بصرياً سطراً بسطر، لكنه لم يُختبر
  بمترجم حقيقي مني.
- أنشأت workflow جاهز (`.github/workflows/flutter_ci.yml`) يُشغِّل
  `flutter analyze` و`flutter test` و`flutter build apk --debug` تلقائياً
  عند أول push — **هذا هو التحقق الفعلي من نجاح البناء**، ويعمل في بيئة
  GitHub Actions الكاملة غير المقيّدة.
- **ملف واحد فقط لم أستطع توليده:** `android/gradle/wrapper/gradle-wrapper.jar`
  (ملف ثنائي). شغّل الأمر التالي مرة واحدة بعد أول `git clone` محلياً:
  ```bash
  cd android && gradle wrapper --gradle-version 8.7
  ```
  أو ببساطة افتح المشروع في Android Studio وسيُنشئه تلقائياً.

**خطوتك الأولى الموصى بها بعد الاستلام:** شغّل `flutter pub get` ثم
`flutter analyze` محلياً وأرسل لي أي خطأ يظهر لأصلحه فوراً قبل الانتقال
للمرحلة الثانية.
